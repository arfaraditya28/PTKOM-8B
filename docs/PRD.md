# Product Requirement Document

## 1. Nama Produk

Portal Layanan Pemerintah

## 2. Status Project

Prototype / Design Trial

## 3. Tujuan

Membuat prototype website layanan pemerintah yang mudah digunakan
untuk menampilkan informasi publik dan menyediakan layanan pengaduan
masyarakat secara digital.

## 4. Target Pengguna

### Masyarakat
Pengguna yang membutuhkan informasi dan layanan pengaduan.

### Petugas
Pengguna yang menangani dan memproses laporan masyarakat.

### Admin
Pengguna yang mengelola sistem dan data layanan.

## 5. Fitur Utama

### Public
- Landing page
- Informasi pemerintah
- Informasi wilayah
- Informasi layanan
- Daftar laporan publik

### Masyarakat
- Registrasi
- Login
- Membuat laporan
- Mengunggah bukti
- Melihat riwayat laporan
- Melacak status laporan

### Petugas
- Dashboard laporan
- Verifikasi laporan
- Mengubah status laporan
- Memberikan tanggapan

### Admin
- Dashboard
- Kelola pengguna
- Kelola kategori
- Kelola laporan
- Kelola data layanan

## 6. Status Laporan

Diajukan
↓
Diverifikasi
↓
Diproses
↓
Selesai

Laporan juga dapat ditolak apabila tidak memenuhi persyaratan.

## 7. Catatan

Project ini masih dalam tahap prototype dan desain.
Struktur fitur, tampilan, API, dan database dapat berubah
sesuai hasil pengembangan dan diskusi tim.
